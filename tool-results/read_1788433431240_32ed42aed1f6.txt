   182→   182→  - Root cause: /api/market/products required both `type` and `city` params, but MarketView omitted `type` when 'all' selected
   183→   183→  - Fix: Modified API to accept 'all' type and return all products; added `getAllProducts()` to game-data.ts; MarketView now always sends `type` param

   185→   185→- **Bug Fix 2 - Sticky TopBar covers BusinessDetail tabs**:
   186→   186→  - Root cause: Tabs were outside the sticky hero banner div, so when scrolled, the sticky header covered the tabs
   187→   187→  - Fix: Moved TabsList inside the sticky div (integrated with hero banner), restructured Tabs component to wrap both sticky area and scrollable content
   188→   188→
   189→   189→- **Bug Fix 3 - 25 active events accumulated**:
   190→   190→  - Root cause: Event duration was calculated as `durationDays * 24 * 60 * 60 * 1000ms` (calendar days) instead of game minutes. A 5-day event lasted 5 real days instead of 5 minutes.
   191→   191→  - Fix: Changed to `durationDays * 60 * 1000ms` (1 game day = 1 real minute). Also added event expiration at the start of every game tick (not just every 3 ticks).
   192→   192→
   193→   193→- **Bug Fix 4 - Navigation badge showing 25 on News tab**:
   194→   194→  - Root cause: Badge showed raw event count which was inflated due to bug #3
   195→   195→  - Fix: Capped badge at '9+' for counts over 9; added a small orange dot indicator on the Businesses tab when events are active

   198→   198→  - Root cause: LeaderboardView used plural form unconditionally
